# 智能应用预审打分系统

面向应用竞赛预审场景的智能打分工具：录入申报信息并与大模型联动，抓取应用链接、OpenLab 文章、开源代码仓的真实内容作为评审依据，输出多维加权评分，支持单个评分、批量评分与评分历史。

## 功能特性

- **大模型评审**：基于抓取到的真实内容逐条打分，理由引用来源，避免臆测。
- **多维加权评分**：5 个维度各满分 100，按权重加权为「五维加权分」（满分 100）。
- **加分项**：开源加分（+5，需代码仓可访问且代码与作品一致；**GitHub 代码仓不加分**）、定向揭榜赛题加分（+10，参选前三个赛题），综合总分满分 115。
- **批量评分**：上传表格模板，一键批量打分；支持全局横向校准，保证跨应用可比，结果可导出 CSV。
- **代码仓可访问性检测**：自动探测代码仓，不可访问时标记为「私有」，并回退读取 README 原始内容。
- **评分历史**：单次与批量结果自动留存，支持查看、下载与删除。
- **链接校验**：COSMO Code 应用链接格式无效、缺失或不可访问（如 HTTP 4xx/5xx）时直接计 0 分（disqualified）。

## 评分规则

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 创意度 | 20% | 创意新颖性与差异化程度 |
| 完整度 | 25% | 功能完整度与可运行程度 |
| 场景价值 | 25% | 实际业务价值与应用场景契合度 |
| 设计打磨 | 10% | 交互与视觉的完成度与体验 |
| COSMO Code 使用深度 | 20% | 对 COSMO Code 平台能力的使用深度 |

总分计算公式：

```
综合总分 = 五维加权分（满分 100）
         + 开源加分（+5，代码仓可访问且代码与作品一致）
         + 定向揭榜赛题加分（+10，参选前三个赛题）
       = 满分 115
```

## 技术栈

- 前端：React 18 + Vite + TypeScript + Tailwind CSS v4
- 后端：Node.js + Express
- 抓取：`fetch` + `puppeteer-core`（SPA 兜底）+ `xlsx`（表格解析与导出）

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env` 并按需填写；未配置大模型时后端进入演示模式。

```bash
cp .env.example .env
```

### 3. 启动服务

后端（默认 3001 端口）：

```bash
npm run server
```

前端（默认 5173 端口，开发服务器已配置 `/api` 反向代理到后端）：

```bash
npm run dev
```

也可使用一键脚本同时启动前后端：

```bash
bash start.sh
```

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容） |
| `LLM_API_KEY` | 大模型密钥 |
| `LLM_MODEL` | 模型名称 |
| `GITLAB_TOKEN` | GitLab / GitCode 令牌（可选） |
| `GITLAB_HOSTS` | 允许携带令牌的主机白名单，逗号分隔（可选） |
| `CHROMIUM_PATH` | 无头浏览器可执行文件路径 |
| `PORT` | 后端端口，默认 3001 |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/health` | 健康检查 |
| `POST` | `/api/score` | 单个应用评分 |
| `POST` | `/api/calibrate` | 批量全局横向校准 |
| `POST` | `/api/check-repos` | 代码仓可访问性检测 |
| `GET` | `/api/history` | 读取评分历史 |
| `POST` | `/api/history` | 保存评分历史 |
| `DELETE` | `/api/history/:id` | 删除评分历史 |

## 批量表格模板

在「批量评分」标签页下载表格模板，按列填写：应用名称（选填）、赛道、赛题、COSMO Code 应用链接、OpenLab 文章链接、开源代码仓。上传后系统会预览全部字段并校验链接格式，确认无误后一键批量打分。模板内含独立「填写示例」表，示例行会被自动跳过。
